# 4PILLARS Retirement Resilience

Open-source policy research on retirement income, Social Security resilience, worker protections, and fair transition design.

## Purpose

This repository studies practical paths to more durable retirement security. Every proposal should identify who benefits, who bears risk, fiscal assumptions, and transition protections for people already relying on existing systems.

## Initial questions

- Which financing options improve long-term retirement resilience without shifting disproportionate risk to workers?
- How do proposed changes affect low-wage workers, caregivers, disabled people, and near-retirees?
- What can be piloted or phased in without disrupting earned benefits?
- How will outcomes be measured and reported publicly?
