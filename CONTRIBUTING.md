# Contributing to Retirement Resilience

1. Read the [research agenda](docs/RESEARCH-AGENDA.md) and check for an existing issue.
2. Open a policy-proposal issue with a defined jurisdiction, problem, mechanism, evidence, affected groups, and risks.
3. Keep one pull request to one testable claim, policy clause, dataset, or research improvement.
4. Cite sources, label uncertainty, and identify conflicts of interest.

Use the parent Commons [governance model](https://github.com/FOURPILLARSFOUNDATION/4pillars-policy-dao/blob/main/governance/DAO-CONSTITUTION.md) and [policy lifecycle](https://github.com/FOURPILLARSFOUNDATION/4pillars-policy-dao/blob/main/operations/POLICY-LIFECYCLE.md). Do not post personal data, unverified allegations, legal advice, or individualized financial planning.
